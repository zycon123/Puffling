# Orbuff approved native art direction

Approved visual direction on 2026-09-15:

- glossy blue cosmic Orbuff mascot
- warm gold/orange orbital ring accents
- deep navy / space-blue background family
- bright cyan highlights and subtle stars
- clean, readable icon silhouette with no tiny wordmark inside the app icon
- light and dark native splash variants using the same core mascot mark

Production native source assets are generated from vector masters in `assets/` so Android and iOS remain visually consistent at every required size.
