# beta.104 canonical boss reward pool

Current server-authoritative Boss acquisition outcomes are limited to:

`NONE`, `ember`, `volt`, `frost`, `wind`, `prism`, `nova`, `supernova`, `phoenix`.

`NONE` is an explicit no-drop receipt and never mutates inventory. Any acquisition attempt outside this pool fails closed. Future reward-pool expansion must be a reviewed server change and must update validation tests in the same PR.
